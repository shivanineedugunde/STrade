# S-Trade

S-Trade is an Android mobile application designed exclusively for college students to buy, sell, and exchange academic products such as textbooks, lab essentials, stationery, and exam prep guides. The platform fosters sustainability, affordability, and community building by enabling students to reuse items within their campus.

🚀 Features

Secure Authentication – Sign up/login with verified college email IDs (@cvr.ac.in) using Firebase Authentication.

Product Listings – Post items with category, price, condition, description, and multiple images.

Search & Filter – Locate items quickly by applying filters (category, price range, condition).

Favorites – Save products for later reference.

Profile Management – Update user details, view ad history, and mark products as sold.

Direct Communication – Contact sellers via call, SMS, or WhatsApp.

🏗️ System Architecture

Frontend: Android Studio (Java, XML, Material Design)

Backend: Firebase (Authentication, Realtime Database, Storage)

Architecture Pattern: Model-View-Controller (MVC)

Build Tool: Gradle

Deployment: APK generated via Android Studio
